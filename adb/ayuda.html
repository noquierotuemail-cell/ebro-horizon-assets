ADBVolver a la herramienta

CONEXIÓN DIRECTA

Tu coche. Tu ordenador.

Conecta el sistema Android por USB y autoriza el acceso desde su pantalla.

Antes de empezar

Usa Chrome o Edge en un ordenador y un cable USB de datos. Abre la herramienta en una pestaña completa, con el coche estacionado y la pantalla Android encendida.

En el coche tiene que estar habilitada la depuración USB y el puerto elegido tiene que exponer su interfaz ADB. Un puerto que solo carga o actúa como anfitrión para memorias USB no basta. Los pasos para activar ADB dependen de la versión del sistema: el generador v3 permite calcular el código para introducirlo manualmente, pero la herramienta no activa ADB automáticamente ni evita la autorización del coche.

En Safari y en iPhone puedes ver la interfaz, pero esta conexión WebUSB no está disponible.

Si el coche pide VIN y RAND

Abre el generador de código ADB v3, copia el VIN completo y el RAND actual que muestra el coche y pulsa Generar código. Conserva los ceros iniciales del RAND. Introduce el resultado en el menú del coche y activa ADB desde allí.

El cálculo funciona sin ADB conectado y no envía ni guarda esos datos. Si cambia el RAND, calcula un código nuevo. Se ha reproducido el ejemplo público y comprobado el algoritmo; la aceptación en tu coche está pendiente de prueba. Esto no mantiene ADB abierto ni sirve para los formularios de versiones 1 o 2.

Conectar

  1. Conecta el ordenador al puerto de datos del coche.
  2. Pulsa Conectar coche y selecciona el dispositivo Android en el cuadro del navegador.
  3. Acepta la autorización de depuración USB y su huella RSA en la pantalla del coche.

El indicador pasará a Conectado después de que Android autorice la sesión. La versión de Android, el usuario activo, las aplicaciones y el espacio libre se leen del dispositivo.

Si el dispositivo no aparece

Comprueba el cable de datos, el puerto del coche y la depuración USB. Cierra JCarTools, Android Studio, scrcpy u otra sesión ADB que pueda estar utilizando el dispositivo.

En Windows puede ser necesario un controlador USB compatible con la interfaz ADB. Usa el controlador proporcionado para el dispositivo y revisa el Administrador de dispositivos. No sustituyas a ciegas los controladores de otros dispositivos.

Si ya tienes ADB instalado y no necesitas conservar su sesión, puedes ejecutar adb kill-server en tu ordenador para liberar el acceso, y volver a pulsar Conectar coche.

Si no aparece la autorización RSA, desconecta y vuelve a conectar el cable, con la pantalla desbloqueada y la depuración USB activa.

Aplicaciones y archivos

La herramienta utiliza el usuario Android activo del coche. Puedes instalar APK individuales o las partes de una misma aplicación. Al exportar se guardan el APK base y sus splits; no se copian sus datos privados.

Las acciones de desactivar, detener, borrar datos y desinstalar piden confirmación. Una aplicación del sistema puede ser necesaria para el funcionamiento del coche. Android puede rechazar operaciones por falta de permisos.

Las transferencias grandes se guardan directamente en una carpeta cuando el navegador ofrece esa opción. La alternativa en memoria tiene un límite de 256 MiB; una exportación incompleta se señala en el registro y en manifest.json.

Pantalla y consola

Captura obtiene una imagen PNG del dispositivo. Ver en directo utiliza el servidor scrcpy incluido y permite toques, deslizamientos y teclas. El servidor se ejecuta temporalmente en Android al iniciar esa función; no modifica el APK de HABRO.

El vídeo necesita WebCodecs y compatibilidad del sistema Android. Si no puede iniciarse, utiliza Captura. El contenido protegido puede aparecer en negro.

La consola ejecuta órdenes de Android: pm list packages -3 o adb shell pm list packages -3. Órdenes de ordenador como adb install y adb connect no se ejecutan en esta consola. Para instalar y transferir, usa las pestañas correspondientes.

La vista en directo se detiene al cambiar de sección o al ocultar la pestaña. El registro se mantiene durante la sesión y puedes guardarlo como texto. La salida visible conserva hasta aproximadamente dos millones de caracteres.

Todos los recursos incluidos

El HTML, el generador de códigos v3, los estilos, la marca HABRO, el cliente WebUSB, la autenticación RSA, el motor ADB, el decodificador y el servidor scrcpy se sirven con la herramienta. No se descargan desde JCarTools ni desde un CDN al conectar el coche.

Descargar HTML y recursos

Para usar el paquete descargado, descomprímelo y ejecuta python iniciar.py —o py -3 iniciar.py en Windows— dentro de su carpeta. Necesita Python 3. Se abrirá en http://localhost:8765/. También puedes alojar su contenido en un servidor HTTPS.

La clave ADB se conserva localmente en el navegador para reconocer tu ordenador. Los comandos, archivos, aplicaciones y pantalla no se envían a un servidor. Una URL u otro navegador utilizarán su propia autorización.

Estado de validación

Incluye conexión ADB real y recursos locales. Se han comprobado el código, las dependencias y el tratamiento de las respuestas ADB mediante pruebas con transporte simulado. La compatibilidad física con el coche está pendiente de prueba.

La interfaz toma los recursos y estilos vigentes de HABRO. El motor utiliza Tango ADB y scrcpy. Licencias y atribuciones.
