01

ANTES DE CONECTAR

Prepara el coche

Con el coche estacionado, activa ADB en su sistema. Si el menú OTA pide una clave diaria, utiliza la calculadora protegida de HABRO con los datos que solicita la pantalla del coche.

Calcular clave OTA ↗

La ruta para abrir por primera vez el menú de ingeniería depende del sistema y sigue pendiente de confirmar. La web necesita ADB activo para detectar el coche.

Abrir menú OTA con ADB ya conectado

Introduce la clave de seis dígitos. El menú se abrirá en el coche; allí podrás pulsar Open ADB.

Esta acción requiere una sesión ADB conectada y autorizada.

02

CONEXIÓN AUTORIZADA

Conecta por USB

  1. Usa un cable de datos y el puerto del coche que exponga ADB.
  2. Pulsa Conectar y selecciona el dispositivo Android en el navegador.
  3. Acepta la autorización de depuración USB en la pantalla del coche.

Sin conexión USB

Al conectar aparecerán la versión del sistema y el usuario Android.

Para conectar por USB, utiliza Chrome o Edge desde un ordenador.

03

TU ARCHIVO, TU ELECCIÓN

Elige e instala

Selecciona un archivo APK o XAPK de tu equipo.

HABRO selecciona el flujo adecuado según el archivo, el sistema y el resultado de la instalación.

Revisarás el archivo antes de confirmar la instalación.
