El recorrido,
pantalla a pantalla.

Las representaciones de interfaz de esta guía están construidas en HTML para explicar el proceso. No sustituyen las pantallas reales de Home Assistant, pero respetan el flujo que HABRO debe seguir.

1Entrada

Abres HABRO y eliges “Instalar”.

La puerta de entrada para el usuario es app.habroremote.com. En la portada verás el logo de HABRO, el saludo y dos opciones: Instalar o Acceder.

Para una primera instalación, pulsa Instalar. HABRO te explicará que necesita conectarse con tu Home Assistant para continuar.

Estas confirmaciones no son un error: son la forma en que Home Assistant te pide autorización antes de permitir una instalación.

3Bootstrap

Instalas HABRO Installer.

Home Assistant abrirá la ficha exacta de HABRO Installer. No deberías tener que buscarlo manualmente.

Mientras el Installer conserve el modo de arranque manual, deja “Iniciar en el arranque” desactivado. El recorrido previsto es: Instalar → Iniciar → Abrir interfaz web.

4Diagnóstico

HABRO revisa tu sistema.

Una vez dentro del Installer, HABRO comprueba compatibilidad, detecta EBRO Auto y HABRO Companion, verifica los paquetes y prepara la operación.

Este análisis es automático. Si tu sistema ya está listo, no realizará cambios innecesarios. Si necesita instalar, actualizar o reparar, preparará el siguiente paso.

5Seguridad

Se prepara una copia recuperable.

Antes de modificar los componentes activos, HABRO verifica los paquetes y conserva el estado necesario para poder recuperar la instalación si la comprobación final falla.

Después de mostrarte qué va a hacer, HABRO te pide una única confirmación clara para ejecutar la instalación o reparación preparada.

TÚ
Revisa y confirma una vez. La mutación no debe empezar antes de tu aprobación.

6Instalación

HABRO instala y Home Assistant se reinicia.

Después de tu confirmación, HABRO aplica los componentes y Home Assistant se reinicia. Durante unos minutos puedes perder la pantalla del Installer o ver que Home Assistant todavía no está disponible.

No vuelvas a pulsar instalar. El proceso conserva su estado y debe reanudarse desde el mismo journal cuando vuelvas a abrir HABRO Installer.

TÚ
Esperas. Si la pantalla se cierra, vuelve a Ajustes → Aplicaciones → HABRO Installer → Abrir interfaz web.
Este es el momento que más confianza necesita: que Home Assistant se reinicie es parte normal del proceso. Volver a abrir el Installer recupera el progreso; no repite la instalación.

7EBRO

Conectas tu cuenta de EBRO.

Cuando los componentes estén instalados, HABRO abrirá el config flow oficial de EBRO fuera del iframe del Installer.

Las credenciales de EBRO se introducen únicamente ahí. Si HABRO identifica un único vehículo con suficiente confianza, lo seleccionará automáticamente; si hay ambigüedad, te preguntará.

TÚ

8Final

Ves “HABRO está listo”.

El recorrido termina cuando EBRO Auto y HABRO Companion están conectados y cargados. Ese es el estado que indica que ya no queda configuración técnica pendiente.

Desde ahí puedes cerrar HABRO Installer y volver a la aplicación.

9Acceso diario

Añades HABRO a tu pantalla de inicio.

Cuando HABRO ya está lista, puedes añadir la PWA a la pantalla de inicio para abrirla como una app. En navegadores compatibles aparecerá el diálogo de instalación; en iPhone/iPad verás la guía para usar Compartir → Añadir a pantalla de inicio → Añadir.

TÚ

Qué puedes esperar

Los momentos que pueden parecer raros… son normales.

1
Home Assistant te pide varias confirmaciones.Forma parte del mecanismo de confianza para instalar el bootstrap.
2
Home Assistant se reinicia.La pantalla puede desaparecer durante unos minutos. No repitas la instalación.
3
Tienes que volver a HABRO Installer.Si se cerró el WebView: Ajustes → Aplicaciones → HABRO Installer → Abrir interfaz web.
4
Las credenciales EBRO aparecen al final.Se introducen exclusivamente en el config flow oficial de Home Assistant.
5
El final es inequívoco.Solo cuando veas “HABRO está listo” puedes considerar terminado el proceso.
